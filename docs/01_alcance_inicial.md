# Alcance inicial — Delivery Express

## Actores
- Cliente
- Administrador
- Repartidor

## Funciones contempladas
- RF-01 a RF-07: portal del cliente.
- RF-08 a RF-13: panel de administración.
- RF-14 a RF-16: portal del repartidor.
- RNF-01 a RNF-04: seguridad, protección de endpoints, Clean Architecture y flujo de Git.

## Decisiones tecnológicas propuestas
- React + Vite para frontend.
- Python + FastAPI para API.
- PostgreSQL administrado en la nube, con Supabase como opción.
- Render como opción para API y Vercel como opción para frontend.
- GitHub para repositorio y Pull Requests.

## Pendientes de confirmar
- Universidad, facultad, carrera y asignatura.
- Integrantes, carnés y líder de la célula.
- Aprobación final del stack por el equipo/docente.
- Fechas oficiales de entregas por cómputo.
